# 每日星光 · life_mark

纯前端、无后端的微信小程序「每日星光」，用于可视化追踪个人生活习惯。数据全部存储在手机本地，无需服务器、云开发或联网。

## 功能

- **记录页（log）**：以是/否记录四项每日习惯  
  - 🌶️ 是否吃辣  
  - 🍜 是否吃面条  
  - 💪 是否锻炼  
  - 👥 知识库贡献力  

- **图表页（chart）**：类似 GitHub 贡献图的彩色热力图  
  - 过去 30/90/180 天四项习惯坚持情况  
  - 每一天一个格子，有记录/无记录均显示  
  - 点击格子查看当日详情  
  - 统计、导出数据、清空数据  

## 技术说明

- 使用微信小程序原生技术（无云开发、无自建服务器）
- 数据使用 `wx.setStorageSync` / `wx.getStorageSync` 存于本地
- 在微信开发者工具中即可完成开发、调试与运行

## 使用方式

1. 用微信开发者工具打开本项目（选择 `life_mark` 目录）
2. 编译运行，在模拟器或真机中即可使用
3. 记录页填写今日四项习惯后点击「保存今日记录」
4. 图表页查看热力图、切换天数、点击格子看详情、导出或清空数据
